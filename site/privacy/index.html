Privacy

Mount Identity Audit is local by design. The CLI does not include telemetry, analytics, advertising, accounts, or network client code.

Website demo

The demo runs entirely in your browser. Values entered into the form are not stored, uploaded, or sent to any service. The service worker caches only public site files so documentation remains available offline.

Shared reports

Normal CLI reports can contain local paths. Use --share before posting a report publicly; it replaces those paths with neutral labels.

Contact

For a privacy question, open an issue in the public repository.
